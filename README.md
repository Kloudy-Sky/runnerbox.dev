# runnerbox.dev

The site for [runnerbox](https://github.com/Kloudy-Sky/runnerbox): see what your CI costs, and whether a machine you own can take it.

```bash
pnpm install
pnpm dev
```

`pnpm build` runs in CI. Cloudflare Pages builds and deploys `main` to [www.runnerbox.dev](https://www.runnerbox.dev), and Porkbun forwards the bare domain there.
