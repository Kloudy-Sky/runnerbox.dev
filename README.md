# runnerbox.dev

The site for [runnerbox](https://github.com/Kloudy-Sky/runnerbox): see what your CI costs, and whether a machine you own can take it.

```bash
pnpm install
pnpm dev
```

`pnpm build` runs in CI. Pushes to `main` deploy to GitHub Pages only when the repository variable `PAGES_LIVE` is `true`.
